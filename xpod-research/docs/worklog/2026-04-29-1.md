# Volcano GPU 调度迁移工作日志

# 项目概述

任务目标：将 Kubernetes 集群中的 GPU 调度从 HAMi 迁移至 Volcano，解决调度冲突问题，实现 Volcano 对 GPU 资源的统一调度。

执行时间：2026\-04\-28 至 2026\-04\-29

集群环境：

- K8s 版本：1\.24\+

- 容器运行时：containerd

- GPU 节点：gpu\-node\-1 \(192.168.1.121\)，NVIDIA A10 × 1

- 原调度方案：HAMi（已移除）

- 目标调度方案：Volcano \+ vGPU Device Plugin

# 一、迁移背景与问题

## 1\.1 初始问题

集群中同时部署了 HAMi 和 Volcano 两套调度系统，导致：

- GPU 资源管理冲突

- Pod 调度失败 \(UnexpectedAdmissionError\)

- HAMi scheduler 与 Volcano scheduler 争抢资源

## 1\.2 迁移决策

- 移除 HAMi，统一使用 Volcano 进行 GPU 调度

- 保留 vGPU 切分能力（后续可选）

# 三、Volcano vGPU Device Plugin 部署

## 3\.1 镜像拉取问题

问题：v1\.8\.0 和 v1\.9\.0 镜像均无法通过 containerd 自动拉取

解决方案：在 GPU 节点手动拉取镜像

```bash
# 登录 GPU 节点
ssh leo@192.168.1.121

# 手动拉取 v1.9.0 镜像
sudo ctr image pull docker.io/projecthami/volcano-vgpu-device-plugin:v1.9.0

# 验证镜像存在
sudo ctr image ls | grep volcano-vgpu
```

## 3\.2 部署 Device Plugin DaemonSet

```bash
cat <<EOF | kubectl apply -f -
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: volcano-vgpu-device-plugin
  namespace: volcano-system
spec:
  selector:
    matchLabels:
      name: volcano-vgpu-device-plugin
  template:
    metadata:
      labels:
        name: volcano-vgpu-device-plugin
    spec:
      nodeSelector:
        accelerator: nvidia-gpu
      serviceAccountName: volcano-device-plugin
      hostNetwork: true
      hostPID: true
      containers:
      - name: volcano-vgpu-device-plugin
        image: projecthami/volcano-vgpu-device-plugin:v1.9.0
        imagePullPolicy: IfNotPresent
        securityContext:
          privileged: true
        env:
        - name: NODE_NAME
          valueFrom:
            fieldRef:
              fieldPath: spec.nodeName
        volumeMounts:
        - name: device-plugin
          mountPath: /var/lib/kubelet/device-plugins
        - name: nvidia
          mountPath: /usr/local/nvidia
      volumes:
      - name: device-plugin
        hostPath:
          path: /var/lib/kubelet/device-plugins
      - name: nvidia
        hostPath:
          path: /usr/local/nvidia
EOF
```

# 四、调度问题排查与解决

## 4\.1 裸 Pod 调度失败

现象：

```bash
kubectl get pod volcano-vgpu-test -w
```

```text
NAME                READY   STATUS                     RESTARTS   AGE
volcano-vgpu-test   0/1     UnexpectedAdmissionError   0          5s
```

错误信息：

```text
Allocate failed due to rpc error: code = Unavailable desc = error reading from server: EOF
```

## 4\.2 Device Plugin Bug 发现

通过实时监控 Device Plugin 日志发现 panic：

```bash
kubectl logs -n volcano-system -f volcano-vgpu-device-plugin-ldwkf
```

关键日志：

```text
Allocate [&ContainerAllocateRequest{DevicesIDs:[GPU-ea6b93fe-4a35-dc9f-9858-4949770e1b55-1],}]
panic: runtime error: invalid memory address or nil pointer dereference
```

结论：projecthami/volcano\-vgpu\-device\-plugin:v1\.9\.0 存在空指针 bug，导致裸 Pod 分配 GPU 时崩溃。

## 4\.3 临时解决：放弃 vGPU 切分，使用整卡

```bash
cat <<EOF | kubectl apply -f -
apiVersion: v1
kind: Pod
metadata:
  name: volcano-gpu-test
spec:
  schedulerName: volcano
  containers:
  - name: cuda-test
    image: nvidia/cuda:11.0-base
    command: ["nvidia-smi"]
    resources:
      limits:
        nvidia.com/gpu: 1
  restartPolicy: Never
EOF
```

## 4\.4 队列配额问题

现象：Pod 持续 Pending，调度器日志显示：

```text
Queue <default> is overused, ignore it.
```

原因：Volcano 新版本将 pods 作为资源配额，未设置时默认为 0

解决方案：修改 default 队列，添加 pods 配额

```bash
kubectl edit queue default
```

在 spec 中添加：

```yaml
spec:
  capability:
    pods: "100"
```

## 4\.5 最终解决：使用 Volcano Job

原因：直接创建 Pod 需要手动管理 PodGroup，而 Volcano Job 会自动处理

成功 YAML：

```yaml
apiVersion: batch.volcano.sh/v1alpha1
kind: Job
metadata:
  name: vcjob-gpu-2
spec:
  minAvailable: 1
  schedulerName: volcano
  queue: default
  tasks:
  - replicas: 1
    name: gpu-task
    template:
      spec:
        containers:
        - name: test
          image: docker.io/library/busybox:latest
          command: ["sh", "-c", "echo GPU OK && sleep 30"]
          resources:
            limits:
              nvidia.com/gpu: 1
        restartPolicy: Never
```

验证成功：

```bash
kubectl get pods -l volcano.sh/job-name=vcjob-gpu-2 -o wide
```

```text
NAME                     READY   STATUS    RESTARTS   AGE   IP               NODE
vcjob-gpu-2-gpu-task-0   1/1     Running   0          57s   10.244.146.148   gpu-node-1
```

```bash
kubectl logs vcjob-gpu-2-gpu-task-0
```

```text
GPU OK
```

# 六、关键经验总结

## 镜像版本选择：

- v1\.8\.0 不存在 \(404\)

- v1\.9\.0 存在但有空指针 bug，不适合裸 Pod 方式

## 调度方式选择：

- 直接创建 Pod \+ schedulerName: volcano → 失败

- 创建 Volcano Job \(vcjob\) → 成功

## 队列配置：

新版 Volcano 必须显式配置 pods 资源配额

## socket 文件：

Device Plugin 创建 nvidia\-gpu\.sock

Volcano 能正确识别和使用

# 七、后续建议

- 使用 Volcano Job 提交 GPU 任务
