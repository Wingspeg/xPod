## 二、每个节点的操作步骤

### 步骤 1：SSH 进入 VM

```bash
ssh leo@<VM_IP>
```

### 步骤 2：安装 containerd

```bash
sudo apt-get update
sudo -E apt-get install -y containerd
sudo mkdir -p /etc/containerd
containerd config default | sudo tee /etc/containerd/config.toml
sudo sed -i 's/SystemdCgroup = false/SystemdCgroup = true/' /etc/containerd/config.toml
sudo systemctl restart containerd
sudo systemctl enable containerd
```

### 步骤 3：配置 containerd 代理

```bash
sudo mkdir -p /etc/systemd/system/containerd.service.d
sudo tee /etc/systemd/system/containerd.service.d/http-proxy.conf <<EOF
[Service]
Environment="HTTP_PROXY=http://192.168.1.72:7897"
Environment="HTTPS_PROXY=http://192.168.1.72:7897"
Environment="NO_PROXY=localhost,127.0.0.1,192.168.0.0/16"
EOF
sudo systemctl daemon-reload
sudo systemctl restart containerd
```

### 步骤 4：安装 K8s 组件

```bash
sudo apt-get install -y apt-transport-https ca-certificates curl gpg

curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.31/deb/Release.key | \
  sudo gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg

echo 'deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.31/deb/ /' | \
  sudo tee /etc/apt/sources.list.d/kubernetes.list

sudo -E apt-get update
sudo -E apt-get install -y kubelet kubeadm kubectl
sudo apt-mark hold kubelet kubeadm kubectl
```

### 步骤 5：修复 preflight 问题

```bash
sudo apt-get install -y conntrack
echo 1 | sudo tee /proc/sys/net/ipv4/ip_forward
sudo sed -i 's/#net.ipv4.ip_forward=1/net.ipv4.ip_forward=1/' /etc/sysctl.conf
sudo sysctl -p
```

### 步骤 6：导入 pause 镜像

> 从宿主机传输，避免从外网拉取超时。

在**宿主机**上执行：

```bash
scp /opt/k8s-workspace/images/pause-3.10.1.tar leo@<VM_IP>:/tmp/
```

在 **VM** 上执行：

```bash
sudo ctr -n k8s.io images import /tmp/pause-3.10.1.tar
```

### 步骤 7：Join 集群

> 如果 token 过期，在宿主机重新生成：
> ```bash
> kubeadm token create --print-join-command
> ```

```bash
sudo kubeadm join 192.168.1.100:6443 \
  --token mzdhoc.2m5qh2pt2pmw2kbk \
  --discovery-token-ca-cert-hash sha256:5225fbd1221c100a1c542441ad4dd71edc0a5b03e1fb527b9b376edf4563abec
```

### 步骤 8：在宿主机验证节点加入

```bash
kubectl get nodes -w
```

等待节点状态变为 `Ready`。

### 步骤 9：打标签

```bash
# cpu 节点
kubectl label node cpu-node-1 node-role.kubernetes.io/worker=worker
kubectl label node cpu-node-1 xpod.io/node-type=cpu

kubectl label node cpu-node-2 node-role.kubernetes.io/worker=worker
kubectl label node cpu-node-2 xpod.io/node-type=cpu

# data 节点
kubectl label node data-node-1 node-role.kubernetes.io/worker=worker
kubectl label node data-node-1 xpod.io/node-type=data

kubectl label node data-node-2 node-role.kubernetes.io/worker=worker
kubectl label node data-node-2 xpod.io/node-type=data

# gpu 节点
kubectl label node gpu-node-1 node-role.kubernetes.io/worker=worker
kubectl label node gpu-node-1 xpod.io/node-type=gpu
kubectl label node gpu-node-1 accelerator=nvidia-a10

# algo 节点
kubectl label node algo-node-1 node-role.kubernetes.io/worker=worker
kubectl label node algo-node-1 xpod.io/node-type=algo
```

## 三、注意事项

**calico-node 拉镜像失败：** 如果 calico-node pod 卡在 `Init:0/3`，先检查是否缺少 pause 镜像：

```bash
kubectl describe pod <calico-node-pod> -n kube-system | grep -A5 "Events"
```

如果是 pause 镜像拉取超时，用步骤 6 的方式手动导入。

**token 有效期：** kubeadm token 默认 24 小时过期，过期后需要重新生成：

```bash
kubeadm token create --print-join-command
```

**calico-node 需要额外镜像：** calico-node 除了 pause 之外还需要拉取自身镜像，如果代理配置正确会自动拉取。若失败可在宿主机导出后传入：

```bash
# 宿主机导出
sudo ctr -n k8s.io images export /tmp/calico-node.tar docker.io/calico/node:v3.xx.x

# 传入并导入
scp /tmp/calico-node.tar leo@<VM_IP>:/tmp/
ssh leo@<VM_IP> "sudo ctr -n k8s.io images import /tmp/calico-node.tar"
```
